## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Before deployment
1. Replace `https://www.example.com/` in `index.html`, `public/robots.txt`, and `public/sitemap.xml` with the final domain.
2. Add the final domain to the canonical and Open Graph metadata in `index.html`.
3. Confirm that the supplied phone, email and address remain correct.
4. Add only services actually offered and genuine project descriptions/reviews.
5. Submit `https://YOUR-DOMAIN/sitemap.xml` in Google Search Console after deployment.

## Enquiry form behavior
The form validates required fields and opens WhatsApp with a prefilled message. The visitor must press **Send** in WhatsApp; the website does not silently send messages.

## Images
The supplied engineer portrait, company banner/logo and construction photographs are included in `public/images`. `omar-banner.png` is retained as the original business identity banner. The MA logo is used in the footer credit.
